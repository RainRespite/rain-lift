# Rain Lift 网页版 · v1.8（GitHub 开发分支）

添加到 iPhone 主屏幕的离线训练记录工具。无需原生 App 签名。

v1.8 重构全历史 GPT 报告、增加可配置动作负重类型和指定位置排序。版本日期：2026-11-01。训练格式继续为版本 1。本版本交付至 GitHub 开发分支 `codex/rain-lift-v1.8` 与标签 `v1.8.0`，未合并 main 或生产部署；手机日常入口不会自动获得本次分支更新。未来经授权发布时同步 docs/dist，并保留手机原入口。

[GitHub 交付与旧版恢复说明](docs/rollback-v1.8.md)。

## v1.8 增量

- 设置 → 健康与 AI → 生成 AI 分析报告：全部有效已完成历史参与计算，分别展示近 7 / 30 天、最近两次同动作表现、历史基线与全期背景；同名不同身份分开，冲突保护保留。
- 默认五部分精简报告，无内部编号、重复 JSON、失真训练时长或空白健康日期。可切换详细报告、复制精简文本、导出 TXT 与独立详细 JSON。无模型 API、自动上传或自动改计划。
- 动作负重类型独立设置：外部、自重、辅助、尚未确认。可信“引体向上”“龙悬”默认自重，68/73 kg 是体重记录，差异只提示核对；其他动作不按名称猜类型。
- 计划编辑及训练中均有“调整顺序”目标位置菜单。计划先改草稿再保存；训练临时排序保留组、输入、选择与计时，只有主动更新固定计划才同步。
- 训练 `rainlift.web.v1`、健康 `rainlift.health.v1` 不变；新增独立 `rainlift.exercise-meta.v1`。训练、健康、动作类型三份备份分别导出；旧训练 JSON 格式保持 `version:1`。
- [本轮审计](docs/v1.8-audit.md)、[完整交付与真实验收记录](docs/v1.8-delivery.md)、[未来手机更新与真机验收指南](docs/mobile-update.md)。

使用 Safari 打开部署链接 → 分享 → 添加到主屏幕。主屏幕首次打开时联网，进入设置确认“离线使用：已就绪”，再使用飞行模式测试。

记录保存在当前站点的浏览器本地存储中；不上传训练数据。定期导出 JSON 备份。支持导入原生版 JSON，自动转换 Swift 日期格式。不要在导出前删除原生版。

## 功能
- 设置 → 健康与 AI：规范 Apple Health JSON 导入预览、确认保存、来源隔离与去重、7 天趋势、健康导出和指定记录删除。健康单独保存，缺失指标不补值。
- 本地生成训练与健康分析报告，支持主动复制、JSON/TXT 导出后自行发送到 ChatGPT；无付费 API、自动上传或 GPT 自动改计划。
- 固定计划与当天动作调整、排序、移除、跳过、更换。
- 修改已有动作名称会延续同一编号的全部历史，并同步当前计划和训练中的名称；新动作单独创建、使用新编号。历史训练保留当时的名称和组记录。
- 旧版不同动作误用同一编号时，历史页会提示整理：不同动作按历史原名称分开，真正的改名可明确确认。修复前自动保留原始副本，不同编号不会按名称自动合并。
- 训练中未记组动作可直接移除；已记组动作可跳过以保留记录。固定计划调整后需要保存。
- 三个自定义次数快捷键；重量加减、补录、修改和撤销。
- 绝对截止时间的休息倒计时，加减 15 秒、提前结束。
- 训练历史、动作逐组历史及原生备份迁移。
- 按整次训练删除历史，确认后移入“最近删除”；可逐次恢复，重开和导出备份都会保留。已删除记录不参与上次表现，计划及正在进行的训练不受影响。
- 离线缓存、主屏幕图标、可选屏幕常亮。
- 联网打开或返回应用时检查更新，设置内可手动检查；新版就绪后提示刷新，保留本地记录和正在编辑的草稿。

## 明确限制
- 网页不能在离线锁屏或后台可靠定时发出通知；页面可见时尝试提示音，回到页面恢复倒计时。系统锁屏提醒请使用手机系统计时器。
- 清除站点数据、移除网页应用、浏览器存储回收或换手机都可能丢失本地记录。持久化存储申请并不是永久保留保证。
- Safari 和主屏幕环境可能不共享存储；可通过备份迁移。
- 网站采用 Sites 默认私人访问；首次访问可能需登录网站所有者的账户。缓存就绪后的离线运行不需要请求服务器。

## 开发
纯静态 HTML/CSS/ES modules，无外部运行依赖。运行本地 HTTP 服务指向 dist。
发布新版本时同步 docs/dist，更新 sw.js 缓存版本及 index/app/data/health/health-ui/ai-report/exercise-meta/style 的资源版本；先从网络完整缓存再激活，保留训练、健康和类型本地数据。

从旧版升级：本轮尚未发布；未来原入口发布后保留手机主屏幕图标中的原网址，联网打开等待新版下载，按应用提示刷新，设置页确认版本 1.8。不要清除网站数据或删除图标。升级后若提示旧动作关联，进入历史 → 整理这几个动作的历史 → 按这些名称分开记录；自动保留修复前副本。GitHub Pages 和 Sites 两个网址各自持有设备本地数据，不能通过换网址同步历史。

删除训练：历史 → 按训练 → 删除这次训练 → 移入最近删除。恢复：历史 → 最近删除 → 恢复这次训练。按动作查看时先点“查看整次训练 / 删除记录”，避免误以为只删除当前动作。最近删除不自动清空，备份包含可恢复记录。

历史只展示实际记过组的动作：零组动作（包括跳过）自动隐藏，旧记录无需逐条清理。新结束的训练只保存有组记录的动作，全部零组时不新增历史。已练过后跳过的动作及 0 kg 的有效组继续保留。旧历史原始快照和备份不自动重写。


## v1.7 使用与交付

健康协议是 Rain-Lift 自定义 JSON，不是 Apple 官方通用导出，也不能直接导入健康 App 的 ZIP/XML。先在 iPhone 快捷指令导出少量真实步数样本，保存到“文件 → 我的 iPhone”，再通过设置导入并确认。单文件/累计存储最多 2 MiB、10,000 条。

训练 key `rainlift.web.v1`、训练格式版本 `1` 均保留；新健康 key 为 `rainlift.health.v1`。训练备份和健康备份需分别导出。报告 JSON 是分析材料，不能用于恢复。
