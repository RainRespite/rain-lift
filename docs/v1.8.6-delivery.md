# Rain-Lift v1.8.6 交付与恢复

## 基线与改动

开发基线为已发布的 v1.8.5，提交 `859da7955840c21528d572ab6d3d4fd9cb21ab0e`。在 `codex/records-v1.8.6` 上开发，基线测试 273 项通过。正式入口沿用原 GitHub Pages。 [基线提交](https://github.com/RainRespite/rain-lift/commit/859da7955840c21528d572ab6d3d4fd9cb21ab0e)

- 「历史 → 按动作 → 动作详情」新增动作纪录与趋势。范围为最近 30 天、90 天和全部历史，范围同时限定 PR 和图表。按设备时区及训练开始的自然日归档，详情保留实际组时间。
- `records.js` 按动作 ID、原单位、已保存的负重模式和必要时的组内参考体重分组。只取已完成、时间有效、明确归类为普通且有可比负重含义的组。旧未分类、热身、递减、缺少参考体重、未来等样本单列排除计数，原始记录继续可见。沿用动作冲突保护和现有改名谱系。
- 外部负重显示最高工作重量和同重量最高次数。明确质量单位、正重量、2–10 次的外部负重组才参与 Epley 估算。相同纪录按原组时间和稳定 ID 取首条。自重按相同参考体重分开，对照额外负重与次数。辅助重量按原始值绘点，同辅助重量比较次数。
- `records-ui.js` 用本地 SVG 和逐日表格展示。每日最高重量、同重量次数和估算值各自取样，组数和训练次数单独计数。缺日和缺测不补值，折线断开。筛选只存在当前页面，编辑、删除、恢复与身份整理后从历史重新派生。
- 训练 v1/v2、RPE/RIR、权威键、负重语义、健康和完整备份沿用 v1.8.5。曲线浏览无需写入存储。新增两个模块加入 PWA 预缓存，`docs/` 与 `dist/` 共 19 个静态文件逐字节一致。

## 本地恢复点

- 正式源提交以 `v1.8.6` 标记。相邻 `rain-lift-v1.8.6-recovery-20261105` 目录存有 Git bundle 与已验证的独立恢复构建 `1.8.5-recovery.r186-20261105a`。
- 从精确的 v1.8.5 标签重建恢复件。将输出指向新的目录，每次准备新的发布恢复件时使用新的构建 ID。

```sh
node scripts/prepare-v1.8.5-recovery.mjs --baseline v1.8.5 --out /absolute/new-recovery-directory --build-id 186-20261105a
```

正式回滚前保存最新完整备份并关闭其他编辑页。隔离同源验证通过后，经明确授权才以新的恢复提交部署到原网址。核对静态文件、离线就绪与手机上的训练、健康、档案、快照和最近删除。遇到异常先保留原存储与备份，切换到能够处理当前数据的已验证构建。
