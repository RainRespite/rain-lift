# Rain-Lift v1.8.2 本地交付与验收

2026-11-03。分支 `codex/body-profile-v1.8.2`，工作目录 `rain-lift-v1.8.2`；基于 `d5d2bb3`（包含 v1.8.1）。本文保留发布前本地验收结果；随后用户已授权 GitHub 推送与原手机入口发布，实际状态见 [发布记录](v1.8.2-release.md)。没有执行真实手机数据迁移或真机验收。原 `rain-lift-v1.8` 主分支副本保留。

## 怎么使用

1. 首页或设置 → **身体档案 / 修改体重** → 修改身体档案。身高、性别都选填；体重设置一次持续使用，想改时再改，不要求每日填写。上次更新是资料保存时间，不是实际称重日期。
2. 健康与 AI → 动作负重类型，单独将少数动作设为 **自重 + 额外负重**；其余动作保留外部、辅助或尚未确认，一键外部默认及冲突保护继续存在。不会改动作名。
3. 开始新训练会复制当前设置体重。自重页面只输入额外负重，点现有次数快捷按钮；额外 0 代表纯自重。例如参考体重 68、额外 5、10 次，保存两个独立重量并显示参考总负重 73。
4. 从未设置体重也能保存额外负重和次数，体重为 null，总量未知。以后设置档案体重不会自动填回这些组。
5. 修改档案体重只供下一次新训练使用。正在训练时主动点 **更新本次引用 / 补充体重**，手动确认体重，默认仅用于后续新组；勾选时预览本次所有已保存新版自重组的数量和动作，再明确更正。历史新组也可在组编辑中单独修正体重、额外负重与次数。
6. 健康与 AI → 生成 AI 分析报告。默认精简，全部有效完成历史参与分析。体重更新和额外负重分别展示；没有更新的日期不补数，体重参考相同也不表示实际体重必然不变。身高和性别仅在档案中勾选纳入时导出。
7. 设置 → **导出完整备份（推荐）**。换机选择 **恢复完整备份 / 换机**，核对替换范围再确认。完整备份最低使用 v1.8.2 恢复；普通训练单独备份不含档案、健康与类型。

新自动计算仅支持明确 kg 的自重动作。lb／自定义单位继续按原单位记录，不直接与 kg 体重相加。参考总负重是记录口径，不是所有动作的实际机械承重。

## 数据契约与新旧兼容

详见 [审计与契约](v1.8.2-audit.md)。新版自重组的 `load.mode=bodyweight_plus_extra`，独立保存 `bodyWeightKg`、`extraWeightKg`、来源与更新时间；其 `set.weight` 等于额外负重，仅作明确版本下的兼容投影，不是旧版总量。总量派生计算。外部、辅助、未知模式也随新组保存，不随当前类型重新解释。

旧无 load 的原始 weight/reps/date 不变。引体向上、龙悬的旧 68／73 不自动拆成当前体重加额外负重。保留旧已确认“本次体重”的范围与差额说明；旧原值、旧已确认与新模式分流分析。修改类型前固定旧语义；仅通过明确旧训练体重确认补充解释。升级时已经进行的旧训练继续使用旧原重量方式，结束后新训练采用新版输入。

|分区|作用|
|---|---|
|rainlift.web.v1|旧训练来源保留，不被新版新训练覆盖|
|rainlift.web.v2|首次新版训练后成为权威训练，保留完整既有历史，新组与 load 同次写入|
|rainlift.exercise-meta.v1|旧动作类型与旧本次体重来源归档|
|rainlift.exercise-meta.v2|新版类型、默认规则、旧本次体重与旧语义快照，首次修改类型时建立|
|rainlift.body-profile.v1|身高、性别、报告选择、当前体重与稀疏变更历史|
|rainlift.health.v1|原健康存储与协议，核心 health.js 未改|

旧版本已打开的页面即使写旧 key，也不会覆盖新版训练/类型分区。请在实际更新后统一使用新版；旧页面后续写入的旧副本不会自动合并，完整备份会保留新旧分区以便人工核查。不要通过清网站数据或改入口更新。

完整恢复按六个分区校验，先预览、保存完整 before 副本和持久化 undo journal，再写入并移除 journal 提交。部分失败立即回滚；回滚本身被配额阻止时保持锁定，重新打开前先恢复日志，避免使用混合状态。`rainlift.full.before-restore.v1` 可在设置导出。测试包含每个恢复写入点的失败与重启恢复。

训练单独恢复独立校验导入的训练，现有训练损坏时仍可用有效旧备份修复；不可读取的独立健康/类型分区原样保留，不妨碍训练恢复。预览后数据发生改变会拒绝覆盖。训练单独恢复保持档案、体重、健康不变；无法证明对应同一完整 session 的旧语义关联会保存在类型 `.before-training-restore` 原始副本中，不参与新恢复训练的解释。完整备份中的历史快照不根据恢复后的当前体重重算。

v1.8.1 读取器实测拒绝训练 version:2。回滚代码会只看到旧 key，不能理解新版权威分区，不能作为无损回滚方案。先用 v1.8.2 导出完整备份，再决定回滚；不要以旧训练备份覆盖新增历史。本地验收阶段未创建发布标签；后续标签与恢复点见发布记录。
