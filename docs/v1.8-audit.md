## 审计结论

| 检查对象 | v1.7 的实际机制 | 对 v1.8 的要求 |
| --- | --- | --- |
| `dist/data.js` | `rainlift.web.v1`，训练格式 `version:1`；动作按 ID 关联，历史为快照；有显式改名、身份冲突整理、最近删除及恢复 | 保留原始重量、次数、时间、动作 ID 和备份兼容性 |
| `dist/ai-report.js` | 遍历历史时使用 `!within(session.started)` 跳过最近 7 天之外的训练；比较窗口内首末表现 | 移除历史查询窗口限制，单独统计近 7 / 30 天，比较最近两次及历史基线 |
| 报告展示 | 显示动作编号、逐组记录和完整 JSON；逐日列出空白健康及重复缺失项 | 精简报告隐藏内部编号，JSON 独立导出；无可用健康数据用一句说明 |
| 会话时间 | 汇总开始到结束的经过分钟数，并保留组间记录间隔 | 不将经过时间或记录间隔当作实际训练、休息时长；省略不可靠时长 |
| `dist/health.js` | 独立 `rainlift.health.v1`，来源隔离、校验、去重、保守汇总；有损坏、配额及过期页面写入保护 | 复用已有真实健康汇总，不生成恢复评分，不修改健康协议 |
| `dist/health-ui.js` | 本地预览、主动复制、JSON/TXT 导出；没有模型调用 | 保留入口，默认复制精简文本，增加详细预览和独立动作类型备份 |
| `planEditor` | 只操作克隆草稿；上下箭头逐位交换；保存后才更新计划，取消不保存 | 增加明确的目标位置选择，保留原草稿与保存规则 |
| `manage` | 调整正在训练的动作数组并保存本次训练；只有主动更新计划才同步固定计划 | 重排必须保留已记录组、输入、选中动作及休息计时 |

`data.js` 的身份保护与“同名不同 ID”规则继续作为关联边界：名称相似不能证明同一动作。未解决的同 ID 冲突不能因报告隐藏 ID 而被合并或绕过。

## 排序问题：已复现与未证实的部分

**已复现两个训练中问题。** `movement()` 在 `selected` 为 `null` 时回退到数组第一项；首次训练未显式点选动作就重排第一项，当前动作会隐式切到新的第一项。其次，重量和备注原先主要在 `change` 时保存；管理操作触发重新渲染，未失焦的合法输入可能丢失。合成测试中输入的 `67.5` 和备注均可复现此问题。

**没有证据证明固定计划原有数组交换必然存错。** 原有上下移、草稿保存和取消在正常操作下没有复现普遍性持久化错误。原体验问题是只能逐位移动、缺少直接定位入口；v1.8 同时补齐明确操作和回归覆盖，不将未证实的保存缺陷写成事实。

[sorting-before.txt](../qa/v1.8/sorting-before.txt) 保存新回归用例在旧实现上的失败结果。其中前两项直接复现上述旧问题；其余多项因旧版没有 `order-*` 位置菜单而失败，不能把全部 16 项都称作旧版已有 Bug。[sorting-tests.txt](../qa/v1.8/sorting-tests.txt) 为修复后实际执行结果。

## 缓存与更新机制

项目继续是无外部运行依赖的静态 HTML/CSS/ES modules PWA。`dist/` 是本地运行入口，`docs/` 保存同份静态资源供既有发布路径使用；本轮同步文件不代表已经发布。

Service Worker 安装时通过 `cache.addAll` 完整下载应用壳，全部成功后才 `skipWaiting`，激活后清理旧的 Rain-Lift 应用壳缓存并 `clients.claim`。导航读取已安装的 `index.html`；静态模块优先缓存。更新不清理 `localStorage`。应用已有联网、回到前台及手动检查更新机制；新 worker 接管后提示用户刷新，不自动打断编辑。

v1.8 将资源查询版本统一为 `?v=1.8`，缓存名为 `rainlift-shell-v1.8.0-20261101-r3`，新增元数据模块也纳入完整缓存。原有刷新前草稿保护继续保留；完整性、缺失资源失败和离线命中均需在本轮测试中复核。

## 数据保护与验收边界

没有读取真实生产浏览器存储来创建测试，所有新增测试、示例和浏览器验收均使用合成数据。训练与健康模块不因报告生成自动写入；新增负重类型使用独立 `rainlift.exercise-meta.v1`，不升级原训练格式。备份分别迁移，报告 JSON 只作分析材料。

实施前审计、问题复现、开发后自动化、桌面浏览器与 iPhone 真机是不同证据层级。开发后结果和仍待验证的部分统一记录在 [v1.8-delivery.md](v1.8-delivery.md)。
