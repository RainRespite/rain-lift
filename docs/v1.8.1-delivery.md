# Rain-Lift v1.8.1 使用与验收

2026-11-02。手机原入口：https://rainrespite.github.io/rain-lift/ 。本版只增量处理负重类型和解释，不新增名称映射，不执行动作重命名，不按名称跨ID合并，也不访问或覆盖真实手机历史。

## 怎么用

1. 设置 → 健康与 AI → 动作负重类型：先确认少数自重、辅助动作，再点“一键设置未确认动作”。预览实际名称和数量，保存后其余候选一次设为外部负重。显式设置（含尚未确认）、现有自重及辅助保留，身份冲突跳过。
2. 勾选“以后未单独设置的动作也默认外部负重”，可免去重复设置；也可用开关关闭。此默认适用于未单独设置的动作，并非按创建日期判断新旧；显式设置与身份保护优先。关闭不撤销已经批量保存的类型。
3. 自重动作选“自重动作（可加重）”。训练页点“本次体重 / 自重加重”，填这次明确的体重，保存即确认本次自重记录按“体重＋额外负重”解释。你继续按习惯填写原重量，例如体重68、记录73，报告显示体重68＋额外5（原记录73）。
4. 没有本次基准时保留原记录，注明体重与附加未拆分。不从当前体重反推旧训练，不从73猜出68；低于体重的记录提示核对，不自动按辅助解释。不同训练、不同单位不沿用，不自动换算单位。
5. 需要解释明确的旧记录时，在健康与AI中选择正在训练或最近20次有效已结束训练中的某次，单独填写；不批量套用体重。训练没有结构化额外负重字段时，拆分只是按用户明确约定计算的报告说明，不称为实际力学承重。

动作名称来自你当前的实际记录与同ID改名谱系。历史快照保留当时名称；默认报告以当前同ID、同单位名称展示。页面不会写入新的动作名称。

## 数据和备份

训练 `rainlift.web.v1`、健康 `rainlift.health.v1`、训练格式version1保持不变。类型key `rainlift.exercise-meta.v1` 保持；原entries结构保留，增加可选defaultLoadType及bodyweightSessions（训练ID、单位、明确体重）。旧文件缺少新增字段仍可读取，新版导出和恢复保留三项设置。

类型备份含本次体重与默认规则，请用1.8.1及以上恢复；旧1.8不能完整理解新可选字段。训练、健康和类型备份分别保存。配额、损坏和过期页面写入继续保护，批量保存一次写入，失败不提示成功。报告及复制在本地完成，无收费API或自动上传。

## 手机更新与恢复

只在原GitHub Pages入口发布，保持同一origin。联网从原图标进入，保存/关闭编辑后检查更新，新版就绪再刷新，确认设置为1.8.1。不删图标、不清站点数据、不导入合成备份。

恢复点为v1.8.0-pages-20261102（8124dff）及原v1.8.0标签。工作区独立恢复目录保留发布前后Git bundle和部署核对结果。回滚代码时先备份三类数据，在独立分支恢复旧应用壳并设置新rollback缓存名再发布，不force push或用旧训练备份覆盖新历史。旧1.8不理解新增类型字段，体重解释设置须另保留新版备份。

GitHub推送、Pages部署成功和手机实际载入是独立状态。最终远端版本和资源核对写入工作区发布凭据；未取得线上核对前不将手机已更新写成完成。
