# Rain-Lift v1.10.1 交付与恢复

## 本轮结果

计划里的动作分成「固定」和「当日选」两种槽位：固定动作每天自动出现，当日选只在当天勾选后加入今天的训练，勾选按日期保存、换天自动失效，不会改动计划。首页卡片拆成两段并新增「今日训练」当日页；训练开始的顺序是固定动作在前、今天的勾选补在后面。数据只新增两个可选字段，存储分区与备份格式不变。

## 数据与兼容

- 动作记录新增可选布尔 `optional`：缺省或 `false` 都是固定动作，`true` 是当日选。计划新增可选 `daily`：`{date:'YYYY-MM-DD', ids:[动作编号]}`，只保存今天勾选的编号。
- 校验同时收紧：`daily` 的日期必须是完整日期串、`ids` 必须是非空字符串且不含重复项；`optional` 只接受布尔值。不合格数据在写入前抛错，不会污染存储。
- 不新增存储分区、不改存储格式版本：训练仍是 `rainlift.web.v1` / `rainlift.web.v2` 两个分区、`rainlift-web` 格式 v1/v2；六分区完整备份与 `minimumAppVersion` `1.8.2` 均未变化。
- 旧计划没有这两个字段，因此升级后所有动作都是固定动作，训练结果与 v1.9.6 完全一致；v1.9.6 的完整备份导入 v1.10.1 后记录逐条相同，只有真正使用当日功能时才会写入新字段。
- 反向兼容：v1.9.6 的校验器忽略未知字段，能原样读回带动作槽位与当天勾选的数据并继续记组；旧版没有当日页，开始训练会把计划里的动作（含当日选）全部练一遍，不丢字段。
- 动作库条目不带槽位信息：写入动作库时会剥掉 `optional`，固定/当日选只属于某个计划，不会顺着动作身份扩散到别的计划。
- 历史与已完成训练是当时的快照，本轮改动不影响既有记录、进度推荐和备份恢复流程。

## 发布状态与恢复

本地已发布，远端未更新：功能分支 `codex/daily-plan-v1.10.1` 从基线 `b527b70` 起，验收通过后快进合入 `main` 到提交 `0164081`，本地标签 `v1.10.1` 已指向该提交。推送 `main`、推送标签与手机入口（GitHub Pages，`main` 分支 `docs/`）更新均未完成：本轮会话内到 `github.com:443` 的连接全部失败（`SSL_ERROR_SYSCALL`，同时 `curl https://github.com` 也无响应），因此 **origin 的 `main`、远端标签和线上 Pages 仍是 v1.9.6 的状态**，线上文件未做任何核验。网络或 GitHub Desktop 可用后，按既有流程执行 `git push origin main`、`git push origin v1.10.1`，再逐项核对线上 20 个静态文件与 `?v=1.10.1` 资源，核验结果补写在本节、[版本工作记录索引](version-work-records.md) 与 `qa/v1.10.1/pages.txt`。本轮只改原版，参赛版工作区 `rain-lift-v1.9.1`、参赛分支 `contest/v1.11.0` 与参赛站点均未改动。

回退到 v1.9.6 不需要数据迁移：新字段只有 `optional` 与 `daily`，旧版会忽略它们并继续训练计划里的全部动作，历史、动作库、健康与档案数据均不受影响。回退前仍按 [恢复说明](rollback-v1.8.md) 先导出完整备份，避免用旧备份覆盖新的训练历史。

## iPhone 待真机验收

1. 从原主屏幕图标联网打开，等新版缓存后按提示刷新；设置页核对「当前版本：1.10.1」，历史条数与升级前一致。
2. 首页核对每张卡片显示「固定 N · 今日已选 0」并分「固定」「今日」两行，按钮为「今日训练」。
3. 点「今日训练」进入当日页，核对固定动作在前；点一个未勾选的当日选，核对出现在「今日已选」且提示「已加入今天」。
4. 点「＋ 从动作库添加当日动作」，核对弹窗只列非固定动作、可跨主类多选并显示「已选 N」；勾选后确认，核对当日页计数与 toast。
5. 点「开始训练」，核对本次训练是固定动作加今天勾选、顺序固定在前；记录一组后结束训练。
6. 再进当日页，对今天的动作点「设为固定」，核对卡片固定数 +1、`今日已选` 归零；点「改为当日选」核对反向生效且今天仍照旧训练。
7. 打开计划编辑器，核对动作行显示「固定」/「当日选」标签和「固定 N · 当日选 M」，切换后保存生效。
8. 训练中点「调整动作 → 更新固定计划」，核对提示说明当日选与今天勾选保持不变；确认后计划槽位不变。
9. 换到第二天（或改系统日期）再打开，核对昨天的勾选不再出现在今日已选、计划本身未被改写；刷新页面与切飞行模式，核对当日页与训练仍可编辑，控制台无报错。
